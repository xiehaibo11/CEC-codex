# CEC-codex Git Setup

Repository URL:

```text
https://github.com/xiehaibo11/CEC-codex.git
```

## Create a new repository from the command line

```bash
echo "# CEC-codex" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/xiehaibo11/CEC-codex.git
git push -u origin main
```

## Push an existing repository from the command line

```bash
git remote add origin https://github.com/xiehaibo11/CEC-codex.git
git branch -M main
git push -u origin main
```
