# 第 17 课：在线学习与策略进化（摘要）

核心问题：为什么交易策略会随时间衰退，以及如何通过在线学习让策略持续进化。

## 概念漂移（Concept Drift）

核心问题："市场变了，但模型没变"。示例：一个年化35%的选股模型在12个月内收益降至8%，并非代码有误，而是市场结构改变导致原有规律失效。

## 市场的非平稳性 —— 三种衰退类型

- **突变型**（政策变化）
- **渐变型**（Alpha被套利，6-18个月）
- **周期型**（市场状态切换）

## 四层进化体系（递进框架）

1. **信号适应**（最快）- 动态调整交易阈值
2. **模型进化**（中等速度）- 参数更新和特征工程
3. **策略进化**（较慢）- 策略组合重配
4. **架构进化**（最慢）- 根本性系统改造

## 在线学习的三种模式

- **滑动窗口重训**：定期用最近N天数据重训
- **增量学习**：每条数据逐步更新模型
- **指数遗忘**：新数据权重大，旧数据指数衰减

关键技术：概念漂移检测（DDM、ADWIN、Page-Hinkley）和防止灾难性遗忘。

## 实施关键点

- 遗忘因子λ的选择关乎适应速度与稳定性
- 更新频率需平衡：过频繁导致过拟合，过稀疏适应滞后
- 特征重要性监控指导是否需要特征调整
- 漂移检测应先行，确认需要重训后再行动

代码实现涵盖：滑动窗口重训器、漂移监控、重训决策引擎等工程化组件。

**核心理念**："持续适应"而非"周期重学"——在保留历史知识的同时逐步调整以适应新环境，是构建稳定量化系统的关键。
