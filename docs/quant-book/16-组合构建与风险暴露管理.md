# 第 16 课：组合构建与风险暴露管理（摘要）

核心观点："多策略 ≠ 低风险。相关性才是风险的本质。"

典型案例：投资者拥有四个看似优秀的策略（美股动量、科技股趋势、成长因子、多头轮动），但它们的相关性都在0.75以上，实际上都在做多美股科技股。2022年，这个"分散化组合"回撤了35%，比任何单一策略都差。

## 16.1 组合层的必要性

完整系统：信号 → 组合优化 → 风控 → 执行。缺少组合优化层会导致：权重分配凭感觉、相关性不可见、因子暴露隐性、杠杆失控。

**关键区别**：信号强不等于组合质量好。强信号配合高相关性会导致集中风险。

## 16.2 Position Sizing 方法

| 方法 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| 等权 | w_i = 1/N | 简单 | 忽略风险差异 |
| 等波动 | w_i ∝ 1/σ_i | 考虑波动 | 忽略相关性 |
| 等风险贡献 | RC_i = RC_j | 风险均衡 | 计算复杂 |
| 均值-方差 | max(收益/风险) | 理论最优 | 估计误差大 |

例：两个策略（波动率10%和30%），等权配置让高波动策略贡献90%风险；等波动配置使风险贡献均等。

## 16.3 协方差估计与收缩

样本协方差在资产数量接近样本数量时极不稳定（如100只股票1年日数据，T/N≈2.5，需估计5050个参数）。

**Ledoit-Wolf收缩估计**：`Σ_shrunk = δ × F + (1-δ) × Σ̂`

使用建议：T/N > 10 用样本协方差；5-10 建议收缩；2-5 必须收缩；≤2 收缩+降维。

## 16.4 因子暴露管理

常见因子：市场因子（Beta）、风格因子（Size/Value/Momentum/Quality/Volatility）、行业因子。

隐性暴露案例：四个看似不同的选股方法（高ROE、低PE、财务稳健、高分红）实际上都在做多"Quality+Value"因子。因子中性化通过约束优化或对冲实现。

## 16.5 隐性杠杆

区分显性杠杆（借钱）和隐性杠杆（名义敞口超过本金）。例：100万本金配置600万名义敞口，实际杠杆为6.5倍。

- 真实杠杆 = Σ|名义敞口| / 本金
- 风险杠杆 = 组合波动率 / 基准波动率

杠杆陷阱：低保证金幻觉、跨资产叠加、相关性低估、波动率低估。

## 16.6 多策略组合的陷阱

**相关性的两面性**：正常时期相关性0.3，危机时期飙升至0.9（流动性挤压、风险偏好逆转、杠杆清算、恐慌蔓延）。

**Drawdown同步问题**：三个单独回撤15%的策略，完全独立时组合回撤8-10%，高度相关时回撤14-15%。

不同策略类型有不同**容量限制**，继续加仓会导致滑点增加和alpha衰减。

## 16.7 多智能体视角

Portfolio Agent 职责：配置最优权重、计算因子暴露、监控相关性。

与 Risk Agent 的分工：Portfolio Agent 关注"如何配置最优"（事前），Risk Agent 关注"是否超过限制"（事中事后）。

优化频率建议：日内（高频）、每日（主动）、每周（战术）、每月（战略）——权重变化超过阈值时才调整。

## 关键要点

1. 多策略≠分散化，相关性决定分散效果
2. 等权配置让高波动策略主导组合风险
3. 因子暴露可能隐性，需显式监控
4. 隐性杠杆来自名义敞口超过本金
5. 危机时相关性飙升，分散效果失效
