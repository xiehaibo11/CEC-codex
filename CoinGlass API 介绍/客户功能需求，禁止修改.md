# 客户完整需求拆解&通俗解读
## 一、底层交易产品：5/10分钟事件期权合约（区别普通永续合约）
1. 交易规则核心
    - 以**开仓瞬间的价格**作为判定基准线，固定持仓周期：5分钟/10分钟二选一
    - 做多：5/10分钟到期后，市场价格＞开仓价（哪怕高1个点）=盈利；≤开仓价=全部本金亏损
    - 做空：5/10分钟到期后，市场价格＜开仓价（哪怕低1个点）=盈利；≥开仓价=全部本金亏损
    - 判定只看周期结束最终价，中途涨跌不影响结果
2. 行情周期参考：用**1分钟K线**作为指标分析图表，交易周期独立为5/10分钟

## 二、交易核心策略逻辑
1. 只顺大趋势开单，坚决不逆势；优先识别行情底部顺势做多、高位顺势做空
2. 过滤规则（防重复开单关键限制）
    - 已有一笔5/10分钟持仓未到期结算前，**不再生成任何新多空信号、不开新单**
    - 避免同时持仓多笔订单，一单结清才允许下一笔
3. 入场时机硬性要求（消除信号漂移/假信号）
    - K线上生成多/空箭头信号后，**不能立刻入场**
    - 必须等当前出现信号的这根K线完整走完收盘
    - 下一根K线开盘第一秒，统一进场开仓，保证无延迟、信号稳定不消失

## 三、指标可视化要求（极简，无多余杂项）
1. 图表载体：通用K线图，兼容浏览器网页端、本地电脑软件，全平台适配
2. 信号样式：仅两种标识，无多余线条/数值/副图
    - 做多信号：对应K线下方显示**向上箭头**
    - 做空信号：对应K线上方显示**向下箭头**
3. 箭头渲染规则（解决盘中波动假信号消失问题）
    - 盘中K线剧烈波动时箭头临时消失不生效
    - 以**整根K线收盘**为最终判定：K线走完确认有效信号，箭头永久保留在该K线上，不会消失

## 四、数据统计面板（右上角悬浮表格，每日自动重置）
1. 重置时间：每日凌晨00:00点清空昨日全部数据，重新统计当日交易
2. 表格展示核心数据：
    1. 当日总开单数量
    2. 盈利单数、总盈利金额
    3. 亏损单数、总亏损金额
    4. 当日实时胜率、亏损率
3. 交易量预期：日均成交几十笔订单

## 五、整体性能&效果硬性诉求
1. 行情、信号无延迟，指标响应同步盘面
2. 策略算法优先保证**高胜率**，核心优先级高于开单数量
3. 整体程序部署不限载体：浏览器网页工具、本地客户端软件均可开发实现
4. 界面极简：只保留K线+多空箭头信号+右上角统计表格，剔除无关冗余功能

# 精简版一句话总结客户需求
开发一套适配5/10分钟事件期权合约的顺势交易指标工具，基于1分钟K线识别多空趋势箭头信号，K线收盘后下一根开盘第一秒入场，持仓未结清不重复出信号；仅保留上下箭头极简可视化，右上角带每日0点自动重置的交易统计面板，工具可网页/本地软件运行，算法优先保障高胜率，日均几十笔交易。
